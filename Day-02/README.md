##  Key Concept Learned

The most important concept from Day 2:

```python
for i in range(...):       # Row
    for j in range(...):   # Column
        print(...)
```

**Outer loop → Row**

**Inner loop → Column**

Understanding this relationship makes it easier to build different pattern programs.
